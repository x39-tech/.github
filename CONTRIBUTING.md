# Contributing

Thanks for your interest in contributing to x39 projects! We welcome contributions of all kinds.

Our projects generally follow a typical Git workflow, with a `main` branch, feature branches and PRs. We roughly follow [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) for commit messages.

Please read a project's `README.md` and any relevant documentation before contributing code to the project. We often keep developer-facing documentation in a `docs/` directory.

## Use of AI

We welcome contributions to our projects which come from a human who understands the submitted code or text, can explain it, and is responsible for its quality as if they wrote it themselves. We consider it disrespectful to post LLM-generated content verbatim without reviewing, editing, and understanding it fully.

### Code Changes

If you use an AI tool to generate code changes for a project, please review those changes for typical attributes of code quality, including but not limited to correctness, fitness for purpose, clean interface design, conciseness, and clarity, before opening your PR.

Please pay particular attention to AI-generated code comments and documentation. At the time of writing, state-of-the-art LLMs generate poor-quality prose. Many AI-generated docs and code comments are overly verbose, and comments are often inserted where they are not needed at all. If your change includes instances of AI-generated prose, please review those instances with the following criteria:

- Consider whether the comment or paragraph is needed at all
- Consider whether it can be reworded to sound more natural and colloquial
- Consider whether it can be reworded to be more concise

The maintainers reserve the right to be very nitpicky about this.

### Communications

AI should not be used to generate issue or PR comments when communicating with maintainers. We expect issue or PR comments on our projects to be written by humans.

If you are opening an issue, please describe the problem in your own words.

If you are opening a pull request, please explain the proposed changes in your own words. This includes the pull request body and responses to questions. Do not copy responses from an LLM when replying to questions from maintainers or allow an agent to post a response on its own.

If you wish to include context from an interaction with AI in your comments, it must be in a quote block (e.g., using >) and disclosed as such. It must be accompanied by human commentary explaining the relevance and implications of the context. Do not share long snippets.

As an exception to this policy, if you are a non-native English speaker, using an AI tool to directly translate comments written in your own words into English is permitted.

### Examples

Examples of things that are not allowed:

- Point an agent to a GitHub issue, ask it to solve the issue and open a PR, without understanding the issue, the PR, or testing the solution yourself.
- Copy responses from the AI when replying to questions from maintainers, without understanding the question or the response.
